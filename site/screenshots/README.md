# 官网截图素材

将真机或模拟器截图导出为 PNG，按下列文件名放入本目录，官网轮播会自动显示（无需改 HTML）。

| 文件名 | 对应画面 | 建议尺寸 |
|--------|----------|----------|
| `01-stats-slice.png` | 痕迹 · 本周周记入口 | 1170×2532（iPhone 比例） |
| `02-week-playback.png` | 周记播放中的真实章节 | 同上 |
| `03-life-mix.png` | 账单构成或有证据的生活线索 | 同上 |
| `04-today-playback.png` | 今日回放 | 同上 |

**拍摄建议**（与 `APP_STORE_LISTING.md` 一致）：

- 暖色主题、宠物开
- 本周 ≥5 笔、本月 ≥15 笔演示数据
- 首图优先「首页真实记录与今日回放」，勿用空态或设置页

现有 4 张图片来自旧界面，只作为历史参考，不在官网或 App Store 使用。取得通过 `FLOW-93/94` 的当前真机构建后，按 `APP_STORE_LISTING.md` 的截图顺序重新拍摄、脱敏并逐张替换；替换前官网使用 CSS 功能结构示意。
