# 官网截图素材

将真机或模拟器截图导出为 PNG，按下列文件名放入本目录，官网轮播会自动显示（无需改 HTML）。

| 文件名 | 对应画面 | 建议尺寸 |
|--------|----------|----------|
| `01-stats-slice.png` | 看看花 · 本周 · 生活切片卡片 | 1170×2532（iPhone 比例） |
| `02-week-playback.png` | 周切片播放中某一幕 | 同上 |
| `03-life-mix.png` | 生活配方 / 环图 | 同上 |
| `04-today-playback.png` | 今日生活回放 | 同上 |

**拍摄建议**（与 `APP_STORE_LISTING.md` 一致）：

- 暖色主题、宠物开
- 本周 ≥5 笔、本月 ≥15 笔演示数据
- 首图优先「生活切片」，勿用空态或设置页

若文件不存在，首页会显示 CSS 示意屏（占位）。
