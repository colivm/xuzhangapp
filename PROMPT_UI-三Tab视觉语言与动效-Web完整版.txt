产品目标（验收对照用户五条困扰）
================================================================================

1. 结构对了，但要有**记忆点** → 三 Tab 共用「叙账四件套」：刊头 kicker / 左章节线 / 主文 / 斜体收束
2. 控件少了但不**空、白、普通** → 用编排型表面填下半屏（次章区、附录条），不加新功能块
3. 去掉卡片堆叠仍要**精致** → 暖纸材质三层（底 → 容器 → 内容），统一阴影/圆角 token
4. Sheet 不能像**系统表单** → 月记/细查/设置 Sheet 续页同构主屏 journal，生成钮有月记后降级
5. **温柔回望** → 排版节奏 + 暖材质 + 慢动效 + 极淡图形（竖线、符号），禁止冷玻璃+满宽绿 SaaS 感

全程校验：这是在帮用户温柔地看见生活，还是在把叙账拉回管钱工具？
