```text

  traceAppendixStrip        // 「细查这一段 →」浅底条，非漂字

```

A2. traceChapterCard 自上而下（数据用现有函数，不改函数体）：

  · **刊头切换**（弱化控件感）：
      「本周 · 本月」文字切换，active = 字重 + 下划线

  · **叙事** 16pt：`heroNarrativeText`（可从 heroScopedItems 算，不应用 category 筛选）

  · **preview** 13pt muted：`summaryCardSubtitle` / 现有 preview 函数

  · **听听入口**（仪式化，非满宽 SaaS 主钮）：
      文案「听听这一段」；fit-content 或 maxWidth ~240；浅描边 pill + 小播放 icon
      点击仍 `handleSummaryPlaybackTap`；会员锁/无数据 disabled 逻辑不变

  · **票根 slip** 最多 3 条：左侧细竖条 accent + 标题 + muted 金额 + meta
      数据源 `heroScopedItems.prefix(3)`；行点击仍 `editingItem`

  · **空态**：保留插画 + 一句

A3. 从首屏移除：overview 合计大卡、trendChart、filtersPanel、全量列表、独立 summarySliceCard 标题行。

A4. **细查 Sheet**（@State showTraceDetailSheet）：
  · 迁入：periodFilter + categoryFilter + periodPickerSheet
  · meta 一行：「周期 · 分类 · N 笔 · 合计 ¥XX」（金额只此一处）
  · 趋势默认折叠 +「展开走势」；展开显示现有 trendChart
  · 全量 recordListContent
  · **禁止**改 computeTrendData / trendInsightText / PlaybackService

A5. SwiftUI 手感：glassPanel radius 20–24；底部 padding ~120；maxWidth 430。不必抄 Web 每个 hex。

Part B · 复盘 Tab（InsightWebView.swift）
================================================================================

**现状**：周/月/今日三块并列 + 报告生成器气质。
**目标**：对齐 Web — 周记主屏 + 脚注 + 次章区；月记/今日仅 Sheet。

B1. 主屏 `insightContent` 仅保留：

```text
insightJournalCard          // 周记
insightChapterFootnote      // 「周记写到这里。想读更长的，再翻开下面。」
insightNextChapter          // 再读一章
  ├─ 月记邀请卡「这一月 / 翻开月记 →」
  └─ quiet「今日小记（可选）→」
```

  · **删除首屏** monthlyInsightSection / todayInsightSection 整块 UI（逻辑保留，改 Sheet 触发）
  · 删除 22pt「近 7 天生活复盘」报表标题（顶栏 pageTitle 已是「生活复盘」）

B2. insightJournalCard（信纸语法，与痕迹场记区分）：
  · 刊头 kicker：`这周 · M/d–M/d`（复用现有周区间计算）
  · 正文 17pt：`formatWeeklyJournalText` 或 `localWeeklyInsightBlocks` 拼成**一段**叙事（禁止三行 KPI 块）
  · 收束 13pt italic
  · quiet actions 横排：梳理本周节奏 / 分享卡 / 标记类目（仍调现有 homeViewModel 方法）

B3. insightChapterFootnote + insightNextChapter：
  · 脚注与次章 **固定间距 14–20px**
  · **禁止** `Spacer()` / `frame(maxHeight:)` 把次章钉到底（Web 已验证 flex 拉伸会怪）
  · 长屏下方可自然留白

B4. 月记 Sheet（@State showMonthlyInsightSheet）：
  · 结构：kicker「这一月 · yyyy年M月」→ 月记正文 → 收束斜体 → **页脚线** → 四级脚注
  · 脚注层次（勿四个链接同色同重）：
      L1「再写一版/生成」稍强 14pt semibold
      L2「剩余 x/5 次」更淡 12pt 批注
      L3「保存 · 换风格」12pt 更低存在
      L4「更多时间段」单独一行更淡，像附录
  · 有 monthlyReport 时 L1 文案「再写一版 →」
  · **禁止**改 generateMonthlyInsight / trial 计数 enforce 逻辑；只改展示与按钮样式
  · 季/年生成仍放「更多时间段」展开区，quiet 小钮

B5. 今日小记 Sheet（@State showTodayInsightSheet）：
  · 从主屏 quiet 链打开；保留现有 today 生成逻辑
  · 壳对齐 journal kicker，不要报表块
