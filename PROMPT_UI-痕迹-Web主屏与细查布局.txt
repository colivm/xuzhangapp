设计目标（对照用户截图）
================================================================================

痕迹 Tab = **一个主叙事 + 少量入口**，不是功能块列表。

主屏（#statsPage）：
  · 单张 trace-hero-panel
  · 顶部 本周/本月 chip
  · 叙事段 + 切片 preview 一句
  · 全宽「听听这一段」
  · 最多 3 条 slip（对齐首页 home-record-item 气质）
  · 底部 quiet「细查这一段 →」

细查（#traceDetailModal）：
  · 筛选 + 摘要 + 列表收进弹层
  · 工具感可高于主屏，但仍 **先叙后议**，不要报表教练语气

任务 A · 主屏 #statsPage
================================================================================

A1. 保持 **仅 1 张**主 panel + 1 个 trace-detail-link；删除或不要新增第二块 panel/h2。

A2. 周/月 chip（#traceRangeWeekBtn / #traceRangeMonthBtn）
  · 样式对齐截图：浅底 pill 容器 + active 浅绿底
  · 点击继续走 setTraceHeroRange，同步 state.period 与 renderStats

A3. 叙事区
  · #traceHeroNarrative：16px、行距 ~1.6、主色略深（已有 class，微调 CSS 即可）
  · #traceHeroPreview：13px muted，与叙事间距 8px
  · 按钮 #traceHeroPlayBtn 上下 margin 加大（叙事→按钮→列表呼吸感 16～20px）

A4. slip 列表
  · 复用 .home-record-item / .trace-slip-item；分隔线 .trace-slip-divider
  · 首屏固定 slice(0, 3)；时间格式与首页一致（formatRecordTime，M/d HH:mm）
  · 无数据走 #traceHeroEmpty（插画 + 一句），不要留空按钮区

A5. **禁止主屏出现「今天还没有账单可回放」类绿条/Toast 常驻**
  · 该文案仅属于今日回放 emptyMessage
  · 痕迹页播放空态用「本周/本月还没有账单可回放」toast 即可，不要在 hero 顶部插 banner

A6. #traceHeroPlayBtn 无数据时
  · disabled 或点击 toast 提示，视觉 muted（避免空数据仍像强 CTA）

A7. 顶栏
  · stats tab 时 pageTitle 保持「这一段痕迹」（PAGE_TITLES.stats 已有）
  · 不要在 #statsPage 内再加日期大标题（日期只在 slip 行展示）
