问题（用户对现稿反馈）
================================================================================

复盘页按 P3.2 改完后与痕迹页太像：
  · 同款 glass 圆角卡
  · 同款满宽 accent 绿按钮（梳理本周节奏 ≈ 听听这一段）
  · 三段报表体（笔数/金额/占比）≈ 痕迹 hero 叙事

目标：复盘 = **周记/回信**（读），痕迹 = **场记/纪录片**（听+看笔笔）。
两 Tab 可同属「单叙事 + 少量入口」，但 **视觉语法必须可一眼区分**。

================================================================================
设计原则 · 复盘 vs 痕迹
================================================================================

| 维度 | 痕迹（勿动） | 复盘（本 PR） |
|------|-------------|---------------|
| 气质 | 场记、可听可看 | 周记、读完即走 |
| 容器 | glass 卡 + chip | 暖色阅读面 / 栏目标题，弱边框 |
| 主 CTA | 满宽绿「听听这一段」 | **禁止同款绿条** |
| 正文 | 笔数+金额+主题+slip | **一段连贯周记**，数字埋进句子 |
| 列表 | 3 条 slip | **无账单列表** |
| 底部入口 | 细查这一段 → | 这一月的回顾 → / 今日小记 → |

1.3 正文 `#insightJournalBody` — **一段连贯文章**
  · 新增展示 helper（仅 app.js，不改 rangeInsightPayload）：

```js
function formatWeeklyJournalText(report, items) {
  // 用 report.summary / structure 的数据语义，重排为 2–4 句周记
  // 禁止照搬三行报表；禁止「占比约 X%」单独成句
  // 禁止 advice 原句里的「优化消费结构」「预算」「建议关注」

  // 「这周记下来 4 笔，花得不多，其他类冒了几次，像随手记下的小念头。

}
```

  · 空态：「近 7 天还没有足够记录。多记几笔，这里会慢慢长出一周的回信。」
