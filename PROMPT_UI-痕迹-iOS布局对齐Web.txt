1.2 traceHeroPanel 内部顺序（自上而下）：

  A. traceRangeChips
      两个 Button：「本周」「本月」
      点击：仅设置已有 selectedPeriod = .week / .month，useCustomRange = false
      然后依赖现有 render 路径刷新（不要新写筛选算法）
      active 样式对齐 Web：浅底 pill 容器 + 选中浅绿底
      注意：selectedPeriod == .year 或 useCustomRange 时，chip 可都不 active 或保持上次 week/month 显示（不新增状态字段；用现有 selectedPeriod 即可）

  B. traceHeroNarrative（16pt，行距 ~1.6）
      文案来源：复用现有 overviewNarrativeText
      但 hero 区应展示「当前 week/month 范围、不含分类筛选」的叙事
      → 允许新增 private var heroScopedItems: [HomeItem]（仅 View 内日期过滤，复制 filteredItems 的 week/month 分支，不应用 selectedCategory）
      → overviewNarrativeText 若强依赖 filteredItems，可拆为 heroNarrativeText 调用同一 trendInsightText / format 逻辑，数字仍来自 heroScopedItems

  C. traceHeroPreview（13pt subtext）
      文案：复用 summaryCardSubtitle(
        preview: buildSummaryPreview(for: week|month),
        range: …, hasData: …, isMonthLocked: …
      )
      或当笔数 < 3 用现有「先记几笔…」类 fallback（调用现有函数，不改函数体）

  D. tracePlayButton — 全宽「听听这一段」
      点击：仍走 handleSummaryPlaybackTap(range:preview:)（与 summarySliceCard 相同入参）
      会员锁时按钮文案仍「了解会员」（现有逻辑）
      无数据：.disabled(true) + muted 样式（对齐 Web .trace-play-btn:disabled）
      去掉 🎬、22pt「本周生活切片」独立标题行

  E. 可选保留：summaryQuotaFootnote 一行小字在按钮下方（原有函数，不改正文规则）

  F. traceSlipDivider（1px 线，margin 约 18–20pt）

  G. traceHeroSlipList — 最多 3 条
      数据源：heroScopedItems.prefix(3)
      行 UI：复用现有 billRecordRow(item:isFirst:)（已与 HomeView 接近）
      点击：editingItem = item（现有 sheet）
      空态：复用 emptyRecordListText 语义 + 简单插画（可参考 HomeView emptyStateArt 或 Web SVG 气质）
