任务 B · Accordion 行视觉（P0 + P1）
================================================================================

B1. 单行结构（高 56pt，圆角 12，底 #FAFAFA 或 surfaceMuted）：

  [左：族色条 3×3×20pt] [中：主标题 15 Semibold + 副标题 11 tertiary] [右：N 款 + 箭头]

B2. 族色条（装饰用，非 theme token）：

  cyber:         #B84888 · #5A9858 · #48A8B8
  mood_weather:  #C87848 · #88A8B8 · #58A888
  paperverse:    #B84848 · #486878 · #9090A8
  bio:           #6A9870 · #C88878 · #78B068
  orbital:       #D88858 · #586878 · #688898
  brutal:        #606060 · #D85018 · #6888B0

B3. 副标题（11pt tertiary，1 行 truncate），示例：

  赛博朋克    → 「霓虹深渊、全息黄昏…」
  情绪气象    → 「晚霞账、薄雾晨、潮汐…」
  纸境东方    → 「留白、朱砂印、湿墨…」
  自然演算    → 「苔藓、珊瑚、光合…」
  太空通勤    → 「舱窗晨、休眠模式…」
  工业柔光    → 「混凝土、安全橙、网格纸…」

  实现：取该族 themes.prefix(3).map(\.displayName).joined(separator: "、") 即可，勿硬编码维护。

B4. 右侧：「{count} 款」12pt tertiary；收起 › / 展开 ⌄（accent 色）

B5. 展开区：
  · 顶部分隔线 1px #E8EDF2
  · 内容左缩进 12pt
  · 2 列 ThemeSwatchCell 网格，spacing 12
  · 数据源：ThemeResolver.themes.filter { $0.family == family && $0.tier == standard }

B6. 行间距 6pt；区「会员主题」与 Vault 间距 20pt

任务 C · 永久限定 Vault（P0 · 核心）
================================================================================

C1. 容器 LifetimeThemeVault（永远展开，不可折叠）：

  · 圆角 16（大于 Accordion 12）
  · 背景：线性渐变 #F5F0E8 → #EEECF2（全区块，opacity 100%）
  · 描边：1px #C9A64A @ 25% opacity
  · 内边距：16
  · 上下与相邻区间距：24

C2. 头部 HStack：

  左：「永久限定」15 Semibold textPrimary
  右：pill「✦ 永久会员」— 背景 #C9A64A @ 12%，字 #8B6F38 11pt Semibold
      已 lifetime：pill 改「已解锁 ✓」古铜色

  下方 helper 12pt secondary：
  「三款典藏皮肤，随永久会员账号保留。」

C3. 3 swatch 横排（或 3 列 grid），数据源：

  lifetime_gilded_circuit / lifetime_archive_gold / lifetime_neon_cathedral
  displayName 来自 catalog（永享·金线电路 等）

C4. 永久 Swatch 规格（与标准区分）：

  | 属性 | 标准 swatch | 永久 swatch |
  |------|-------------|-------------|
  | 色块 | 56×56 r14 | **64×64 r16** |
  | 未选边框 | 无或 1px stroke | **1.5px 渐变金边** #C9A961→#A68445 |
  | 选中 | 2px accent + ✓ | **2px 古铜 #A68445 + ✓** |
  | 锁 | 居中 lock 或 opacity 0.55 | **右上 18pt 圆** #C9A64A @ 20% + lock 10pt |
  | 名称 | 11 Medium 全黑 | 11 **Semibold**；「永享·」段用 theme accent 色 |
  | 副句 | 无 | 9pt tertiary 一行：结构感 / 最耐用 / 夜间复盘 |

  三款 accent 预览（swatch 内色点）：
  · 金线电路：#B8985C + slate 底 #EEF1F4
  · 档案金章：#A68445 + 纸底 #F2EBE0
  · 琥珀礼拜堂：dark 预览 #100E1A + 琥珀点 #D4A574

C5. 非 lifetime 会员：
  · swatch **opacity 0.92**（不要 0.55 糊片）
  · 保留金边 + 锁角标
  · 点击 → 现有 toast + MemberPricing **锚 lifetime 卡**
  · Vault 底 quiet link：「了解永久会员 →」

C6. lifetime 会员：
  · 无锁角标，保留金箔边
  · 可选：选中款时 Vault 底边 2px #A68445（静态即可，动画 P2）
