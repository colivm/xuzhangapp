  lifeEntryNoteEditor：仅 noteEditorExpanded

  amountAssist 编辑时可 hidden

================================================================================
4.3 life-slip 交互（与新建一致）
================================================================================

自己写一句 → noteEditorExpanded=true，focus titleInput

换个角度 → openScenePackMoreSheet()

================================================================================
4.4 meta 日期（编辑专有）
================================================================================

编辑态 meta 反映该笔实际日期，非一律「今天」：
  今天：{分类} · 今天 H:mm（H:mm 取自 item createdAt）
  非今天：{分类} · M月D日（或 yyyy-M-D，与列表 muted 一致）
  改日期后 updateLifeEntryPreview 刷新 meta

不改 tier 判定。
