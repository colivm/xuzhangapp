================================================================================
要解决的问题
================================================================================

当前 iOS 左卡「记一笔」是整块 accent 绿底 + 白字，像旧版「+ 快速记账」大按钮。
Web 预览已验证更好看：两张等权 glass 卡，横排小圆图标 + 文案，左卡仅淡 accent 染，右卡白玻璃。

本 PR 只把双动作卡收成 Web 同款质感，Hero 首卡不动。

================================================================================
目标视觉（对齐 web-preview .home-action-card）
================================================================================

布局：
  HStack：左侧 icon 圆徽章（约 34pt）+ 右侧 VStack（标题 strong + 副标题 small）
  卡片 minHeight ~78–108，圆角 20，padding 13–16
  两卡等宽、等权，禁止左卡实心主色块

左卡（记一笔 · isPrimary）：
  背景：glass 白 + 淡 accent 渐变（约 accent 12–22% 混入 panel），非 accent.opacity(0.9) 实色
  边框：accent 18–38% 混 glass-border
  图标圆底：accent 13% 填 + 细描边；glyph 用「＋」或细线 plus，accent 色，非 .white
  标题/副标题：AppColors.text / subtext（禁止白字）

右卡（听今日回放）：
  背景：白玻璃 opacity ~0.66–0.78，与现有非 primary 接近但统一语法
  图标：▶ 或 play 细线风格，accent 色圆底
  文案：text / subtext

阴影：轻 shadow（y:4–6, opacity 0.08），禁止强 accent 绿晕
