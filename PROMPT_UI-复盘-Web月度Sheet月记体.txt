背景（用户对现稿反馈）
================================================================================

主屏周记已定稿（暖色 .insight-journal + 一段正文 + quiet actions）。
但点开「这一月的回顾 →」仍像报告工厂：
  · 胶囊绿「生成这一月的回顾」
  · 三段报表（总支出 / 占比 / 教练 advice）
  · 「柔和下月参考」等 chip

目标：月度 Sheet = **读一封月记**，不是「点生成看 KPI 报告」；气质延续主屏，不与痕迹绿钮撞脸。

2.1 新增（app.js）：

```js
function formatMonthlySheetKicker(monthKey) {
  // "2026-06" → "这一月 · 2026年6月"
}

function formatMonthlyJournalText(report, monthItems) {
  // 有 monthItems 即可写；有 report 时参考其语义
  // 输出 2–3 句连贯月记，禁止三行 KPI
  // 禁止：「占比约 X%」单独成句、「预算上限」「下月更容易看见结构变化」
  // 示例：
  // 「六月记下来 4 笔，花费很轻，其他偶尔露头。
  //   没有哪一类占满整个月，更像几处被留下的注脚。」
}

function formatMonthlyJournalClosing(monthItems) {
  // 感受性收束，对齐 formatWeeklyJournalClosing 语气
  // 示例：「愿意的话，下个月再翻开对照看看。」
}

function formatMonthlyJournalPlaceholder() {
  return "这一月还没有回顾。点下面生成，会在这里长出一封月记。";
}
```

2.2 renderInsight 月度段逻辑：

  · monthlySheetKicker ← formatMonthlySheetKicker(monthKey)
  · 若 monthlyReport 存在且非 generating：
      monthlyJournalBody ← formatMonthlyJournalText(monthlyReport, monthItems)
      monthlyJournalClosing ← formatMonthlyJournalClosing(monthItems)
  · 若无 report：
      monthlyJournalBody ← formatMonthlyJournalPlaceholder()
      monthlyJournalClosing ← ""
  · generating 时 journalBody 用 skeleton 或「正在梳理这一月…」

  · **禁止**再把 monthlyReport.summary/structure/advice 原文插入 DOM
