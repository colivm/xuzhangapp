背景（产品意图）
================================================================================

主屏复盘 = 暖色周记（.insight-journal）；点「这一月的回顾 →」打开 #monthlyInsightModal（P3.2b 已收束为月记体）。
用户期望：像 **再展开一页信纸** 读出月记，不是黑板拉下、不是 KPI 报表砸脸。

复盘动效语法 = **纵向展开 + 书写淡入**（与痕迹横向翻页区分）。
禁止：黑板色、表格飞入、数字滚动、满屏 accent 动画。

任务 2 · 打开 Sheet（app.js）
================================================================================

2.1 改 openMonthlyInsightModal()：

```js
function openMonthlyInsightModal() {
  setUIModal("monthlyInsight");
  const modal = refs.monthlyInsightModal;
  modal?.classList.remove("hidden");
  // 重置动效态
  modal?.classList.remove("monthly-sheet-opened");
  refs.monthlyJournalBody?.classList.remove("monthly-journal-revealed");
  refs.monthlyJournalClosing?.classList.remove("monthly-journal-revealed");
  requestAnimationFrame(() => {
    modal?.classList.add("monthly-sheet-opened");
    queueMonthlyJournalReveal();
  });
}
```

2.2 新增 queueMonthlyJournalReveal()：

  · 若 state.isGeneratingMonthlyInsight：只给 body 加 .monthly-journal-generating（CSS 柔和 pulse），不 reveal
  · 否则：延迟 180–220ms（等 Sheet 升起过半）后给 body + closing 加 .monthly-journal-revealed
  · placeholder 与已生成月记 **同一套 reveal**（都是「读信」）

2.3 closeMonthlyInsightModal：移除 monthly-sheet-opened、monthly-journal-revealed、monthly-journal-generating。

任务 4 · CSS 动效（styles.css）
================================================================================

4.1 **Sheet 入场**（在现有 .ocr-overlay 基础上叠加，不覆盖全局）：

```css
.insight-monthly-modal {
  transform-origin: top center;
}
#monthlyInsightModal:not(.hidden) .insight-monthly-modal {
  /* 覆盖默认 ocr-modal 仅 scale 入场，叠加信纸感 */
  animation: monthlySheetUnfold 0.52s var(--ease-out-soft) forwards;
}
@keyframes monthlySheetUnfold {
  0% {
    opacity: 0;
    transform: translateY(24px) scale(0.98);
    clip-path: inset(0 0 100% 0 round 30px);
  }
  55% {
    opacity: 1;
    clip-path: inset(0 0 8% 0 round 30px);
  }
  100% {
    transform: translateY(0) scale(1);
    clip-path: inset(0 0 0 0 round 30px);
  }
}
```

  · 背景保持 P3.2b 暖白渐变；**禁止**深绿/黑板色 #1a1a1a 背景
  · 左竖线装饰（若主屏有 .insight-journal 左边框）可在 .monthly-journal-body 复用 2px accent mix，随 clip 展开

4.2 **正文揭示** .monthly-journal-revealed：

```css
.monthly-journal-body:not(.monthly-journal-revealed) {
  opacity: 0;
  transform: translateY(10px);
}
.monthly-journal-body.monthly-journal-revealed {
  opacity: 1;
  transform: translateY(0);
  transition: opacity 0.48s var(--ease-out-soft), transform 0.48s var(--ease-out-soft);
}
.insight-journal-closing.monthly-journal-revealed {
  transition-delay: 0.12s;
  /* 同上 opacity/transform */
}
```

4.3 逐行版（若实现 wrapMonthlyJournalRevealLines）：

```css
.monthly-journal-line {
  display: block;
  opacity: 0;
  transform: translateY(8px);
  animation: monthlyJournalLineIn 0.4s var(--ease-out-soft) forwards;
  animation-delay: calc(var(--line-i) * 90ms + 100ms);
}
```

4.4 **生成中** .monthly-journal-generating：
  · 不用 skeleton-line 闪烁（可保留 skeleton class 但覆盖 animation 为柔和 opacity 0.55↔1，周期 1.6s）
  · 文案「正在梳理这一月…」保持静态，不要打字机

4.5 .monthly-generate-link / quiet actions：**无** hover 弹跳；最多 color 0.2s。

4.6 **prefers-reduced-motion: reduce**：
  · 禁用 clip-path animation；Sheet 仅用 opacity
  · 正文同时显示，无 line stagger
